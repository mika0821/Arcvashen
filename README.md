# Hotel & Restaurant Website

This is a clean, mobile-first static website for a hotel and restaurant in Armenia. It is ready to upload to GitHub Pages.

## Files

- `index.html` — website structure
- `styles.css` — design and responsive mobile styling
- `script.js` — language switcher, rooms, menu, and scroll animation
- `assets/` — logo, favicon, and placeholder illustrations

## How to edit

1. Open `script.js`.
2. Change the hotel name in `brandName` for `hy`, `ru`, and `en`.
3. Change the address in `addressValue` for `hy`, `ru`, and `en`.
4. Edit room names/details inside the `rooms` arrays.
5. Replace the SVG images inside `assets/` with real hotel and restaurant photos when you have them.

## GitHub Pages

Upload all files to your GitHub repository. Keep `index.html` in the main/root folder. Then enable GitHub Pages from repository settings.
